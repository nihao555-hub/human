# PRD：Human IP Studio 本地优先 AI 口播智能体

## 1. 文档信息

- 版本：v0.1
- 日期：2026-07-16
- 目标读者：业务负责人、产品、设计、研发、算法、测试、交付团队
- 产品代号：Human IP Studio
- 核心约束：语言模型可调用 API；除语言模型外，所有核心能力按本地部署 / 本地推理设计。

## 2. 背景与目标

短视频口播 IP 工具的用户核心诉求是“低成本、高频、稳定地产出口播视频”。参考产品已经跑通了从抖音文案提取、文案改写、声音克隆、视频对口型、字幕、封面到导出的基础链路，但存在稳定性、效果、编辑能力、成本透明度和跨平台体验不足。

Human IP Studio 的目标不是复刻一个黑盒流水线，而是打造“本地视频内容工厂”：

- 面向小白：一键生成一条可发布的视频。
- 面向运营团队：批量生成、质量检查、模板化生产。
- 面向专业用户：每个环节可预览、可编辑、可替换模型。

## 3. 产品定位

一句话定位：

**本地优先、效果可控、可批量生产的 AI 口播 IP 视频工作台。**

差异化承诺：

1. 数据本地：用户素材、声音、形象、视频默认不上传第三方云端。
2. 成本透明：除语言模型 API 外，不依赖外部付费算力；每条视频展示预计耗时、显存占用和 LLM Token 成本。
3. 效果更稳：内置音视频预检、质量评分、字幕排版检测、失败重试。
4. 可编辑：字幕、封面、语速、分镜、BGM、口型片段支持导出前手动调整。
5. 可扩展：模型适配层允许替换 ASR、TTS、对口型、封面生成等本地模块。

## 4. 目标用户

| 用户 | 痛点 | 关键需求 |
| --- | --- | --- |
| 个人自媒体 / 知识博主 | 不想真人出镜，缺少剪辑能力 | 一键生成、低学习成本、稳定导出 |
| 短视频代运营团队 | 需要多账号、多模板、批量产出 | 批量任务、账号人设库、模板复用、团队协作 |
| 教培 / 咨询 / 本地生活商家 | 有素材和知识，但不会包装内容 | 私有知识库、行业话术、合规模板 |
| MCN / 内容工厂 | 成本、产能、质量一致性 | 本地 GPU 队列、多机协作、质量标准化 |
| 开发 / AI 爱好者 | 想替换模型、二次开发 | 模块化接口、模型管理、日志可观测 |

## 5. 成功指标

### 5.1 MVP 成功指标

- 首次安装到跑通 Demo 视频：≤ 30 分钟。
- 30 秒口播视频在推荐硬件上生成成功率：≥ 90%。
- 30 秒口播视频端到端生成耗时：≤ 6 分钟（RTX 4090）；≤ 12 分钟（RTX 3060 12GB）。
- 字幕导出无溢出率：≥ 95%。
- 关键错误可读率：100% 关键错误给出中文原因与修复建议。

### 5.2 V1 成功指标

- 1 分钟视频生成成功率：≥ 90%。
- 批量任务 20 条连续执行成功率：≥ 85%。
- 用户导出前平均人工修改时长：≤ 5 分钟 / 条。
- 唇形主观评分：≥ 4/5。
- 付费用户 7 日留存：≥ 35%（需上线后验证）。

## 6. 范围定义

### 6.1 P0：MVP 必做

1. 桌面端工作台
   - Windows 优先，macOS Apple Silicon 同步验证。
   - 设备体检：CPU、GPU、显存、内存、磁盘、驱动、FFmpeg、模型文件。
   - 本地模型安装 / 校验 / 更新。

2. 项目与素材管理
   - 本地项目库：项目、素材、输出、日志。
   - 支持导入视频、音频、文案、人物照片 / 视频片段。
   - 音视频预检：格式、时长、分辨率、码率、声道、采样率、人脸可检测性。

3. 文案能力
   - 输入方式：粘贴文案、导入文本、粘贴抖音 / 公开视频链接。
   - 抖音链接解析：短链、详情页、精选页、用户页带 modal_id。
   - 解析失败兜底：提示用户下载视频后走本地 ASR 提取。
   - LLM API 改写：爆款结构、口播化、分段、标题、敏感词初筛。
   - 支持自带 LLM API Key 和模型配置。

4. 语音能力
   - 本地 TTS / 声音克隆：基于授权样本生成口播音频。
   - 支持音频上传、录音、格式自动转码。
   - 语速、停顿、情绪、分段试听。

5. 数字人口播 / 对口型
   - 输入：人物视频 + 生成音频。
   - 本地对口型模型，支持短视频生成。
   - 任务进度、预计剩余时间、失败重试。
   - 输出无字幕基础视频。

6. 字幕与导出
   - 本地 ASR / 对齐生成字幕。
   - 字幕样式模板：字体、字号、描边、阴影、位置、每行字数、最大行数。
   - 导出前预览，检测字幕超出画面。
   - FFmpeg 本地合成导出 MP4。

7. 封面
   - 从视频抽帧。
   - LLM API 生成标题候选。
   - 本地模板编辑：标题、副标题、人像 / 产品图、贴纸、颜色。
   - 导出 9:16、1:1、16:9 封面。

8. 质量与日志
   - 任务状态：排队、运行、暂停、取消、失败、完成。
   - 失败可恢复：保留中间产物，可从失败环节重跑。
   - 质量检查：无人脸、口播音频过长、字幕溢出、黑帧、音量过低、导出失败。

### 6.2 P1：正式版增强

1. 批量生产
   - 多文案、多音色、多模板组合生成。
   - 批量任务队列、并发数控制、夜间渲染。
   - 批量导出 Excel / CSV 任务报告。

2. 人设与知识库
   - 账号人设：领域、口吻、禁用词、目标人群、常用 CTA。
   - 本地知识库：上传 PDF / Word / Markdown / 文本，用于生成专业文案。
   - 选题库与内容日历。

3. 高级编辑
   - 时间线：音频、视频、字幕、BGM、贴纸分轨。
   - 字幕逐句编辑和重新对齐。
   - BGM 库、音量 ducking、淡入淡出。
   - 画面调色：亮度、对比度、饱和度、锐化。

4. 多模型策略
   - 对口型质量档：快速 / 标准 / 高质量。
   - 模型健康检查与性能 benchmark。
   - 模型 Adapter SDK。

5. 多平台发布辅助
   - 导出不同平台规格包。
   - 标题、话题、简介生成。
   - 浏览器自动化半自动发布，保留人工确认。

### 6.3 P2：超越版

1. 本地多机渲染
   - 局域网 GPU 节点发现。
   - 任务分发、失败转移、资源监控。

2. 质量评分系统
   - 唇形同步评分。
   - 字幕可读性评分。
   - 封面点击率启发式评分。
   - 平台风险评分。

3. 素材智能组装
   - 自动从长视频切出可口播片段。
   - 自动识别产品图、背景图、人物图。
   - 一条文案生成多版 A/B 测试视频。

4. 私有化团队版
   - 本地局域网部署。
   - 用户、角色、授权、审稿流。
   - 团队素材库与模板库。

## 7. 用户流程

### 7.1 新手一键流程

1. 打开 App，完成设备体检。
2. 选择“新建口播视频”。
3. 粘贴对标视频链接或输入主题。
4. 选择人设模板、音色、人物视频。
5. 点击“一键生成”。
6. App 自动执行：提取 / 生成文案 → 语音 → 对口型 → 字幕 → 封面 → 质检。
7. 用户预览，必要时修改字幕和封面。
8. 导出视频与封面。

### 7.2 专业编辑流程

1. 新建项目并导入素材。
2. 在文案页生成多个脚本版本。
3. 在语音页逐段试听和调整停顿。
4. 在对口型页选择模型质量档。
5. 在时间线页调整字幕、BGM、封面。
6. 运行质检，修复问题。
7. 导出多平台规格。

### 7.3 批量生产流程

1. 导入选题 / 文案表格。
2. 选择账号人设、音色、模板、输出规格。
3. 设置并发数和质量阈值。
4. 任务队列本地执行。
5. 完成后查看失败原因和批量报告。
6. 批量导出或进入人工复审。

## 9. 非功能需求

### 9.1 性能

- 推荐硬件：RTX 4070 12GB 以上、32GB 内存、SSD 200GB 可用空间。
- 最低可用：RTX 3060 12GB、16GB 内存，默认快速档。
- 高质量档：RTX 4090 24GB 或同级显卡。
- 模型服务启动后 5 秒内返回健康状态。
- 任务执行时展示显存、耗时、阶段进度。

### 9.2 稳定性

- 所有生成任务必须持久化状态。
- App 崩溃重启后可恢复任务列表和中间产物。
- 模型进程与桌面进程隔离，模型崩溃不导致 UI 崩溃。
- 失败日志脱敏，不记录 API Key 明文。

### 9.3 安全与合规

- API Key 本地加密存储。
- 声音克隆和肖像生成前要求用户确认授权。
- 默认添加可选 AI 生成标识 / 水印。
- 支持敏感词、极限词、医疗金融高风险表达提示。
- 不提供绕过平台审核、冒充他人、伪造证据等功能。

### 9.4 可维护性

- 模型 Adapter 统一接口：`prepare(input) -> run() -> validate() -> artifacts`。
- 中间产物目录结构固定，便于排查。
- 日志分为用户日志和开发日志。
- 版本升级不得破坏旧项目打开。

## 10. 技术架构建议

### 10.1 客户端架构

```text
Desktop UI（Tauri / Electron）
  ├─ Project Manager
  ├─ Prompt & Script Studio
  ├─ Audio Studio
  ├─ Avatar / Lip-sync Studio
  ├─ Subtitle & Cover Editor
  └─ Export & Quality Report

Local Runtime（FastAPI / Python）
  ├─ Job Queue（SQLite + file lock）
  ├─ Model Manager
  ├─ ASR Service
  ├─ TTS / Voice Clone Service
  ├─ Lip-sync Service
  ├─ Video Compose Service（FFmpeg）
  ├─ Quality Check Service
  └─ LLM API Adapter

Local Storage
  ├─ projects/
  ├─ assets/
  ├─ models/
  ├─ cache/
  ├─ exports/
  └─ logs/
```

### 10.2 模型策略

| 模块 | MVP 推荐 | V1 备选 |
| --- | --- | --- |
| ASR | faster-whisper 或 SenseVoice Small | SenseVoice + 标点 / 情绪识别 |
| TTS | CosyVoice2/3 | GPT-SoVITS 适配、音色库 |
| 对口型 | MuseTalk 或 VideoReTalking | LatentSync 512 高质量档 |
| 人脸检测 | MediaPipe / 商用友好替代 | 多检测器兜底 |
| 封面 | 本地模板引擎 | 本地 ComfyUI / SD / FLUX 可选 |

注意：LivePortrait 等方案如依赖 InsightFace 权重，商业使用前需替换为许可证友好的检测器。

## 13. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 本地模型效果不稳定 | 视频不可用 | 多模型质量档、质检、人工修正入口 |
| 硬件差异大 | 用户安装失败 | 设备体检、性能档降级、推荐配置透明 |
| 抖音链接解析失效 | 文案提取失败 | 本地下载 / ASR 兜底、解析器可热更新 |
| 开源模型许可证限制 | 商业风险 | 上线前法务复核，替换非商用依赖 |
| 声音 / 肖像侵权 | 合规风险 | 授权确认、素材来源留痕、默认水印 |
| 跨平台打包复杂 | 交付延期 | Windows 优先，macOS 分阶段验收 |

## 14. MVP 验收清单

- [ ] Windows 安装包可安装、启动、卸载。
- [ ] 设备体检能识别至少 3 种硬件档位。
- [ ] 用户可粘贴文案并生成 30 秒口播音频。
- [ ] 用户可上传授权声音样本并完成本地声音克隆。
- [ ] 用户可上传人物视频并生成对口型视频。
- [ ] 字幕预览与导出一致，无明显溢出。
- [ ] 用户可基于视频帧制作封面。
- [ ] 一键导出 1080x1920 MP4。
- [ ] 失败任务可重试，日志能定位失败环节。
- [ ] API Key 不出现在日志和导出文件中。
