# 开发成本评估：Human IP Studio

## 1. 估算前提

1. 语言模型使用 API，支持用户自带 API Key。
2. 除语言模型外，核心能力本地部署：ASR、TTS / 声音克隆、对口型、字幕、封面、视频导出、任务队列、文件存储。
3. 不从零训练基础模型，优先集成商用友好开源模型与本地推理框架。
4. 首发以 Windows 为主，macOS Apple Silicon 做同步架构预留和基础验证。
5. 估算以“对外商业可交付产品”为口径，不只是技术 Demo。
6. 人力成本按外包 / 项目报价口径估算，已包含项目管理、沟通、测试、基础文档，但不含大规模市场投放、客服团队和法务专项费用。

## 2. 成本结论

| 版本 | 周期 | 团队规模 | 人月 | 建议报价区间 | 适合目标 |
| --- | --- | --- | --- | --- | --- |
| 技术验证 Demo | 2-3 周 | 2-3 人 | 2-3 人月 | ¥8-15 万 | 证明本地链路可跑通 |
| MVP | 8-10 周 | 5-6 人 | 12-16 人月 | ¥45-80 万 | 单机端到端生成 30 秒视频 |
| V1 商业版 | 4-5 个月 | 7-9 人 | 28-40 人月 | ¥100-180 万 | 批量生产、可编辑、可售卖 |
| 超越版 / 团队版 | 6-8 个月 | 9-12 人 | 55-80 人月 | ¥200-350 万 | 多机渲染、质量评分、团队协作、插件生态 |

推荐路线：  
**先做 2-3 周技术验证，再投入 8-10 周 MVP；如果 Demo 指标达标，再进入 V1。**  
直接承诺完整超越版风险较高，因为对口型效果、跨平台打包和本地模型兼容性需要实测。

## 5. 分阶段计划

### 阶段 0：技术验证 Demo（2-3 周，¥8-15 万）

目标：验证本地部署可行性和效果下限。

交付：

- 本地 ASR 提取字幕 Demo。
- 本地 TTS / 声音克隆 Demo。
- 本地对口型 Demo。
- FFmpeg 合成字幕 Demo。
- 30 秒样例视频端到端脚本。
- 模型许可证初筛表。
- 推荐硬件 benchmark。

验收：

- 在 RTX 4090 和 RTX 3060 12GB 至少各跑通 1 条视频。
- 记录每个阶段耗时、显存和失败点。
- 输出是否进入 MVP 的技术决策报告。

### 阶段 1：MVP（8-10 周，¥45-80 万）

目标：普通用户可在单机桌面端完成 30 秒口播视频。

交付：

- Windows 安装包。
- 桌面端项目管理。
- LLM 文案生成 / 改写。
- 本地声音克隆 / TTS。
- 本地对口型。
- 字幕样式和导出。
- 封面模板。
- 任务状态、取消、重试、日志。
- 设备体检和模型管理。

验收：

- 30 秒视频端到端成功率 ≥ 90%。
- 导出视频可直接发布。
- 常见错误有中文修复建议。

### 阶段 2：V1 商业版（8-10 周增量，累计 4-5 个月，¥100-180 万）

目标：具备售卖价值，明显优于参考产品。

交付：

- 批量生产队列。
- 账号人设库、本地知识库。
- 时间线编辑。
- 长视频分段对口型。
- 多模型质量档。
- 质量报告。
- macOS Apple Silicon 基础版。
- 多平台规格导出和半自动发布。

验收：

- 1 分钟视频成功率 ≥ 90%。
- 20 条批量任务连续执行成功率 ≥ 85%。
- 字幕 / 封面 / 音频 / BGM 可导出前编辑。

### 阶段 3：超越版 / 团队版（12-16 周增量，累计 6-8 个月，¥200-350 万）

目标：构建内容工厂和团队协作能力。

交付：

- 局域网多 GPU 节点调度。
- 高级质量评分。
- A/B 多版本生成。
- 团队素材库、模板库、审稿流。
- 插件化模型市场。
- 企业私有化部署包。

## 7. LLM API 成本

LLM 只用于文案生成、改写、标题、封面文案、合规提示，不用于视频推理。

单条视频大致消耗：

- 轻量文案改写：2k-5k tokens。
- 多版本生成 + 人设 + 合规检查：8k-20k tokens。
- 批量 1000 条：约 200 万-2000 万 tokens。

成本区间取决于模型：

| 模型档 | 适用 | 1000 条视频估算 |
| --- | --- | ---: |
| 低成本模型（DeepSeek / Qwen 等） | 常规文案、标题 | ¥20-300 |
| 中档模型 | 稳定改写、合规检查 | ¥300-1,500 |
| 高端模型（GPT / Claude 高规格） | 高质量策划、复杂行业 | ¥1,500-8,000+ |

建议产品设计：

- 默认支持用户自带 API Key。
- 显示每次调用预估 Token 和成本。
- 支持“低成本 / 高质量 / 自定义模型”三档。
- Prompt 和输出本地缓存，避免重复计费。

## 8. 主要不确定性与缓冲

| 不确定性 | 建议缓冲 |
| --- | --- |
| 本地对口型模型效果达不到商业要求 | 预留 20%-30% AI 工程缓冲 |
| Windows / macOS 打包和 GPU 驱动差异 | 预留 2-3 周兼容性测试 |
| 开源模型商业许可证复核 | 上线前预留 1-2 周法务 / 替换时间 |
| 抖音等平台链接解析频繁变化 | 做插件化解析器和 ASR 兜底 |
| 用户硬件跨度大 | 设备体检 + 性能档 + 明确硬件门槛 |
| 字幕 / 封面编辑体验反复 | 设计阶段先做可交互原型 |

建议报价中保留至少 15%-25% 风险缓冲。

## 9. 报价建议

如果这是给客户的商业评估，建议不要只报“低价复刻”。参考产品已经证明基础链路可做，但公开反馈说明真正值钱的是稳定性、效果、体验和本地部署交付。

建议报价方式：

1. **技术验证包：¥10 万左右**  
   先验证模型链路、硬件和效果，降低后续风险。

2. **MVP 包：¥60 万左右**  
   交付可安装、可生成、可导出的单机产品。

3. **商业版包：¥120-160 万**  
   加入批量、编辑、质量检测、跨平台、模型管理，具备售卖能力。

4. **超越版包：¥220 万起**  
   加入团队版、多机渲染、质量评分、插件化模型和私有化交付。

## 10. 是否能“超越他们”的投入判断

低于 ¥50 万：可以做出可演示 MVP，但很难在稳定性和效果上系统性超过参考产品。  
¥100-180 万：可以做出明显更好用的商业版，重点赢在稳定、可编辑、批量和质量检查。  
¥200 万以上：可以做内容工厂级产品，建立长期壁垒。

最建议的投入路径：

```text
2-3 周 Demo 验证
  -> 8-10 周 MVP
    -> 小范围真实用户内测
      -> 根据失败数据投入 V1
```

这样能避免一开始就把预算押在不确定的模型效果上。
