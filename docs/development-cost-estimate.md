# 直接成本评估：Human IP Studio

## 1. 统计口径

本文只统计项目实际需要向外支付的成本：

- 开发与测试硬件。
- LLM API 调用。
- 可选云 GPU 测试。
- Windows / macOS 签名证书。
- 安装包和模型文件的存储、下载、CDN。
- 可选监控和法务合规服务。
- 本地运行产生的电费和存储扩容。

明确不统计：

- 我们自己的开发报酬。
- 人工成本、人月成本。
- Devin / AI 编程的“代码费用”。
- 按代码行数计价。
- 第三方开源项目本身的代码价值。

AI 编程目前没有统一的“每行代码单价”。如果不计算我们的报酬，代码量不应进入成本表。

## 2. 核心结论

### 2.1 已有高配电脑

| 阶段 | 预计周期 | 一次性直接成本 | 说明 |
| --- | --- | ---: | --- |
| 技术验证 Demo | 3-5 天 | ¥500-3,000 | API、少量云 GPU 或存储 |
| MVP | 2-4 周 | ¥3,000-20,000 | API、证书、SSD、可选云 GPU |
| V1 商业版 | 6-10 周 | ¥20,000-80,000 | 多设备测试、签名、分发、可选法务 |
| 超越版 / 团队版 | 3-5 个月 | ¥80,000-250,000 | 多机测试、NAS、企业分发、合规 |

### 2.2 没有开发与测试硬件

| 阶段 | 预计周期 | 一次性直接成本 | 主要新增 |
| --- | --- | ---: | --- |
| 技术验证 Demo | 3-5 天 | ¥30,000-50,000 | 1 台 RTX 4090 工作站 |
| MVP | 2-4 周 | ¥60,000-120,000 | 4090 主机、普通显卡测试机、SSD |
| V1 商业版 | 6-10 周 | ¥100,000-220,000 | 完整 Windows / macOS 测试矩阵、证书、分发、法务 |
| 超越版 / 团队版 | 3-5 个月 | ¥180,000-500,000 | 多 GPU 节点、NAS、更多终端和企业分发 |

最现实的预算判断：

- 如果已有一台 RTX 4090：MVP 的外部支出大约 **¥0.3-2 万**。
- 如果什么硬件都没有：MVP 的外部支出大约 **¥6-12 万**。
- 做可正式售卖的 V1：已有硬件约 **¥2-8 万**；需补齐设备约 **¥10-22 万**。

### 3.3 用户侧硬件

用户自己本地运行时，硬件由用户承担：

| 档位 | 配置 | 参考购置价 | 适合场景 |
| --- | --- | ---: | --- |

这部分不应计入我们的开发成本，但应在商业方案中明确告知客户，避免产生“软件免费但必须买高配电脑”的隐性成本争议。

## 4. LLM API 成本

LLM API 只用于：

- 文案生成与改写。
- 标题、话题、简介。
- 人设风格。
- 封面文字。
- 敏感词和合规提示。

ASR、声音克隆、TTS、对口型、字幕、封面渲染和视频导出均在本地执行，不产生云端模型调用费。

### 4.1 单条视频用量

| 场景 | 预计 Token |
| --- | ---: |
| 单次轻量改写 | 2k-5k |
| 文案 + 标题 + 话题 | 5k-10k |
| 多版本 + 人设 + 合规检查 | 10k-25k |

### 4.2 批量成本

| 用量 | 低成本模型 | 中档模型 | 高端模型 |
| --- | ---: | ---: | ---: |
| 100 条视频 | ¥2-30 | ¥30-150 | ¥150-800 |
| 1,000 条视频 | ¥20-300 | ¥300-1,500 | ¥1,500-8,000+ |
| 10,000 条视频 | ¥200-3,000 | ¥3,000-15,000 | ¥15,000-80,000+ |

开发期间的 API 成本：

- Demo：约 ¥50-300。
- MVP：约 ¥300-1,500。
- V1 完整测试：约 ¥1,000-5,000。

如果支持用户自带 API Key，产品上线后的 LLM API 费用可以由用户自己承担。

## 5. 可选云 GPU 成本

产品正式运行不依赖云 GPU。开发阶段可短期租用，用于：

- 在购买硬件前验证模型。
- 对比不同对口型模型。
- 压力测试。
- 临时并行生成测试样本。

| 用途 | 费用估算 |
| --- | ---: |
| 4090 / L20 / A10 单卡 | ¥5-20 / 小时 |
| Demo 50-100 小时 | ¥500-2,000 |
| MVP 200-500 小时 | ¥2,000-10,000 |
| V1 多模型 benchmark | ¥5,000-20,000 |

已有本地 4090 后，这项成本可以接近 ¥0。

## 6. 证书与分发成本

### 6.1 桌面应用签名

| 项目 | 费用 | 必要性 |
| --- | ---: | --- |
| Windows 代码签名证书 | ¥1,500-6,000 / 年 | 商业版建议购买，减少杀毒软件误报 |
| Apple Developer | $99 / 年，约 ¥700-800 | 发布 macOS 签名和公证需要 |

参考产品用户反馈中已经出现“杀毒软件阻止运行”。因此 Windows 签名证书属于比较重要的直接成本。

### 6.2 安装包和模型文件分发

本地模型文件可能达到几十到几百 GB，分发成本取决于是否让用户单独下载模型。

| 方案 | 成本 | 说明 |
| --- | ---: | --- |
| 网盘 / 用户手动下载 | ¥0-1,000 / 年 | 最便宜，体验一般 |
| 对象存储 + CDN | ¥100-2,000 / 月 | 取决于下载量和模型包大小 |
| 用户自行配置模型目录 | 接近 ¥0 | 操作门槛高 |
| 离线硬盘交付 | ¥300-1,500 / 套 | 企业私有化可选 |

MVP 可以先用网盘或对象存储，不必建设复杂下载平台。

## 7. 存储、电费和本地运行成本

### 7.2 电费

| 使用方式 | 月电费估算 |

| 每天运行 4 小时 | ¥50-150 |
| 每天运行 8 小时 | ¥100-300 |
| 24 小时持续批量运行 | ¥300-900 |

用户侧本地运行电费由用户承担；团队版自建渲染节点则需要计入运营成本。

## 10. 最终建议

最省钱的推进方式：

```text
已有电脑或租 4090 云 GPU
  -> ¥500-3,000 做 3-5 天 Demo
    -> 效果达标后再买 4090
      -> ¥0.3-2 万直接成本完成 MVP
        -> 有真实客户后再补测试机、Mac、证书、CDN 和法务
```

如果目前没有任何硬件：

```text
先租云 GPU 做 Demo
  -> 不达标：损失约 ¥500-2,000
  -> 达标：再投入 ¥6-12 万完成 MVP 所需硬件和直接费用
```

在“不计算我们自己的报酬”的前提下，这个项目真正需要支付的主要成本是显卡电脑，而不是代码或 LLM API。
