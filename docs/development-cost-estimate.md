# 开发成本评估：Human IP Studio（Devin / AI 编程口径）

## 1. 估算前提

1. 开发方式按 Devin / AI 编程高效率模式估算，不按传统外包团队长期人月报价。
2. 语言模型使用 API，支持用户自带 API Key。
3. 除语言模型外，核心能力本地部署：ASR、TTS / 声音克隆、对口型、字幕、封面、视频导出、任务队列、文件存储。
4. 不从零训练基础模型，优先集成商用友好开源模型与本地推理框架。
5. 报价可拆成两类：
   - **直接成本**：硬件、API、证书、存储、打包、测试设备、可选云 GPU 验证。
   - **代码量 / 交付计价**：按有效业务代码量、模块难度、集成风险计费。
6. 本文不把“人工成本”作为主要报价依据；如果需要对客户报价，建议使用“代码量 + 复杂度 + 直接成本 + 风险缓冲”的方式。

## 2. 成本结论

| 版本 | Devin/AI 开发周期 | 预计有效代码量 | 代码量计价建议 | 直接成本 | 总报价建议 | 适合目标 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 技术验证 Demo | 3-5 天 | 2k-4k 行 | ¥1-3 万 | ¥0.5-3 万 | ¥2-6 万 | 跑通本地链路和效果验证 |
| MVP | 2-4 周 | 12k-25k 行 | ¥8-20 万 | ¥3-15 万 | ¥12-35 万 | 单机端到端生成 30 秒视频 |
| V1 商业版 | 6-10 周 | 35k-70k 行 | ¥25-60 万 | ¥8-25 万 | ¥40-90 万 | 批量生产、可编辑、可售卖 |
| 超越版 / 团队版 | 3-5 个月 | 80k-160k 行 | ¥70-160 万 | ¥20-60 万 | ¥100-220 万 | 多机渲染、团队协作、插件生态 |

推荐路线：

**先用 3-5 天做技术验证 Demo，再用 2-4 周做 MVP；等真实视频效果和硬件耗时确认后，再报价 V1。**

这比传统人月口径短很多，但仍要保留本地模型、打包、显卡兼容和许可证复核的风险缓冲。

## 3. 代码量计价模型

### 3.1 有效代码量定义

有效代码量只计算为产品交付服务的代码，不建议把第三方开源模型、自动生成依赖、lock 文件、模型权重、二进制文件计入报价。

应计入：

- 桌面端 UI、状态管理、项目管理。
- 本地 API 服务、任务队列、模型 Adapter。
- 音视频处理、字幕、封面、导出。
- LLM Prompt 模板、配置管理、质量检查。
- 安装脚本、打包脚本、诊断工具。
- 自动化测试、端到端样例脚本。

不应计入：

- 第三方开源仓库原始代码。
- 模型权重文件。
- 自动生成的构建产物。
- vendored 依赖。

### 3.2 按模块单价

| 模块类型 | 建议单价 | 原因 |
| --- | ---: | --- |
| 普通 CRUD / 配置 / 文档型代码 | ¥3-6 / 行 | 逻辑明确，AI 生成效率高 |
| 桌面端 UI / 状态管理 | ¥6-12 / 行 | 交互调试、跨平台兼容成本较高 |
| 本地 Runtime / 任务队列 | ¥8-15 / 行 | 需要稳定性、恢复、日志 |
| 音视频 / FFmpeg / 字幕 | ¥10-20 / 行 | 调试成本高，边界多 |
| 模型 Adapter / GPU 推理集成 | ¥12-30 / 行 | 依赖环境、显存、模型效果 |
| 打包安装 / 自动更新 / 诊断 | ¥10-25 / 行 | Windows/macOS 差异大 |
| 测试和基准脚本 | ¥5-12 / 行 | 可复用，但需要覆盖硬件矩阵 |

实际报价建议不要机械按总代码行数乘单价，而是用模块分档：

```text
模块报价 = 预计有效代码量 × 模块单价 × 风险系数
风险系数：
  低风险：1.0-1.2
  中风险：1.2-1.5
  高风险：1.5-2.0
```

## 5. 分阶段计划（Devin/AI 编程口径）

### 阶段 0：技术验证 Demo（3-5 天，建议报价 ¥2-6 万）

目标：用最少代码验证本地链路和效果。

交付：

- 本地 ASR 提取字幕脚本。
- 本地 TTS / 声音克隆脚本。
- 本地对口型脚本。
- FFmpeg 字幕合成和导出脚本。
- 一条 30 秒样例视频端到端流水线。
- 模型许可证初筛表。
- 耗时、显存、失败点 benchmark。

不做：

- 完整 UI。
- 批量任务。
- 安装包。
- 自动更新。

验收：

- RTX 4090 和 RTX 3060 12GB 至少各跑通 1 条视频。
- 输出是否进入 MVP 的技术决策报告。

### 阶段 1：MVP（2-4 周，建议报价 ¥12-35 万）

目标：普通用户可在单机桌面端完成 30 秒口播视频。

交付：

- Windows 桌面端。
- 项目管理、素材导入、设备体检。
- LLM 文案生成 / 改写。
- 本地声音克隆 / TTS。
- 本地对口型。
- 字幕样式、封面模板、MP4 导出。
- 任务状态、取消、重试、日志。
- 简易安装包。

验收：

- 30 秒视频端到端成功率 ≥ 85%-90%。
- 导出视频可直接发布。
- 常见错误有中文修复建议。

### 阶段 2：V1 商业版（6-10 周，建议报价 ¥40-90 万）

目标：具备真实售卖能力，明显优于参考产品。

交付：

- 批量生产队列。
- 账号人设库、本地知识库。
- 字幕 / 封面 / 音频可视化编辑。
- 长视频分段对口型。
- 多模型质量档。
- 质量报告。
- macOS Apple Silicon 基础版。
- 多平台规格导出和半自动发布。
- 签名安装包、崩溃日志、升级机制。

验收：

- 1 分钟视频成功率 ≥ 85%-90%。
- 20 条批量任务连续执行成功率 ≥ 80%-85%。
- 参考产品公开反馈中的高频问题有明确优化：链接兜底、字幕不溢出、任务可取消、失败可重试、封面可编辑。

### 阶段 3：超越版 / 团队版（3-5 个月，建议报价 ¥100-220 万）

目标：内容工厂和团队协作。

交付：

- 局域网多 GPU 节点调度。
- 高级质量评分。
- A/B 多版本生成。
- 团队素材库、模板库、审稿流。
- 插件化模型 Adapter。
- 企业私有化部署包。

## 7. 如何对外解释“比传统报价低但能做”

可以这样表达：

1. 这个产品不从零训练模型，核心是工程集成、工作流、桌面端和本地部署。
2. Devin / AI 编程能显著压缩 CRUD、脚手架、UI、测试脚本和集成代码的开发时间。
3. 真正的风险不在“写代码”，而在：
   - 本地模型效果是否可商业接受。
   - GPU / 驱动 / 打包兼容。
   - 字幕、对口型、导出的一致性。
   - 开源模型许可证和肖像 / 声音合规。
4. 所以报价应按“分阶段验收”而不是一次性承诺完整大系统。

## 8. 是否能“超越他们”的投入判断

低于 ¥10 万：可以做技术 Demo 或内部演示，不建议承诺商业售卖。

¥12-35 万：可以做 MVP，能跑通端到端，并在稳定性上比参考产品更清晰，但功能不会很全。

¥40-90 万：可以做商业版，重点超越参考产品的字幕、封面、批量、任务恢复、质量检查和本地部署体验。

¥100 万以上：可以做内容工厂级产品，形成多机渲染、团队协作和插件化模型壁垒。

最建议的投入路径：

```text
3-5 天 Demo 验证
  -> 2-4 周 MVP
    -> 小范围真实用户内测
      -> 6-10 周商业版
```

这样既利用 Devin 降低开发周期，又避免一开始把预算押在不确定的本地模型效果上。
