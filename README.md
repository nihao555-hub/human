## 核心约束

- 语言模型使用 API。
- 除语言模型外，文案提取、ASR、TTS、声音克隆、数字人对口型、字幕、封面、导出、任务队列、文件存储等能力均按本地部署设计。
- 产品目标不是简单复刻，而是在稳定性、画面效果、可编辑性、批量效率、跨平台兼容、质量检测和合规能力上超过参考产品。
